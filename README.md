# Corion Browser

**4.20 — Bug Sweep 2.0 · Windows 10 / 11 · x64**

> **4.20 is the last version of Corion on GitHub.** Starting with the next update, Corion won't be posted here anymore and this GitHub page will be made private, so these download links will stop working. New versions will be announced on [corion.space](https://corion.space). Corion 4.10 and 4.0 are retired; 4.20 installs over them and keeps your profile.

A personal Windows browser by Coritex Studio, with a customizable homepage, split view, research tools and visible privacy controls. This is an early release with incomplete website compatibility.

[Download the installer](https://github.com/hithaixo-max/Corion-Browser/releases/download/v4.20.0/Corion-4.20.0-win-x64-setup.exe) · [Website](https://hithaixo-max.github.io/Corion-Browser/) · [Release notes](https://github.com/hithaixo-max/Corion-Browser/releases/tag/v4.20.0) · [SHA-256](https://github.com/hithaixo-max/Corion-Browser/releases/download/v4.20.0/Corion-4.20.0-win-x64-setup.exe.sha256)

4.20 remembers fullscreen, warms up the start page and confirms the taskbar menu and extensions manager work. 4.10 fixed page-script timeouts that could close the browser, adds Undo for Watches and page notes, download-rule testing and download summary notifications. 4.0 added dormant tab restoration, conservative automatic tab management, a command palette, unified local library, workspaces, offline text reading, setup and selective local backup/recovery tools. It updates the engine to Chromium 156 and the runtime to .NET 10.
